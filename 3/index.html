Project 03

Fun with Flow Models

This project explores flow matching, a generative modeling technique that transforms random noise into meaningful images. I first experimented with a pretrained flow model to understand image generation, editing and guidance, then built and trained my own UNet-based flow-matching models on MNIST to generate handwritten digits.
